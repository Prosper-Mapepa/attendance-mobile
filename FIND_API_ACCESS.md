# How to Find API Access from Where You Are

You're currently on the **"App integrity"** page. Here's how to get to **"API access"** to link your service account.

## 🎯 From Your Current Location

### You Are Here:
- **Section:** Test and release
- **Page:** App integrity

### You Need to Go To:
- **Section:** Setup
- **Page:** API access

## 📍 Step-by-Step Navigation

### Step 1: Look at the Left Sidebar

1. Look at the **left sidebar** (navigation menu on the left side of the screen)
2. You should see sections like:
   - Dashboard
   - Statistics
   - Publishing overview
   - **Test and release** ← You are here
   - Monitor and improve
   - Grow users
   - Monetize with Play
   - Store presence
   - **Setup** ← You need to go here!
   - Policy

### Step 2: Find "Setup" Section

1. Scroll down in the left sidebar (if needed)
2. Look for **"Setup"** section
3. It should be below "Store presence" and above "Policy"

### Step 3: Expand "Setup" Section

1. Click on **"Setup"** in the left sidebar
2. It will expand to show:
   - App access
   - **API access** ← Click this!

### Step 4: Click "API access"

1. After clicking "Setup", you'll see sub-items
2. Click **"API access"**
3. This will take you to the page where you can link your service account

## 🚀 Quick Method: Direct URL

If you can't find it, use this direct URL:

**https://play.google.com/console/developers/api-access**

Just paste this in your browser address bar (make sure you're logged into Play Console first).

## 🔍 Alternative: Use Search

1. Look for a **search bar** at the top of Play Console
2. Type: **"API access"**
3. Click on the result that says "API access" under "Setup"

## ✅ What You'll See on API Access Page

Once you're on the API access page, you should see:

1. **"Google Play Android Developer API"** section at the top
   - Status: Enabled (or a button to enable it)

2. **"Service accounts"** section below
   - This is where you'll see the "Link service account" button
   - This is where your linked service accounts will appear

## 📋 Complete Path Summary

**From App integrity page:**
1. Look at **left sidebar**
2. Scroll to find **"Setup"** section
3. Click **"Setup"** to expand
4. Click **"API access"**
5. Scroll to **"Service accounts"** section
6. Click **"Link service account"** button

## 🆘 Still Can't Find It?

### Check These:

1. **Is the sidebar collapsed?**
   - Look for a **☰ (hamburger menu)** icon in the top-left
   - Click it to expand the sidebar

2. **Are you on the right app?**
   - Check the top of the page - should say "AttendIQ"
   - If not, click "All apps" and select AttendIQ

3. **Do you have the right permissions?**
   - You need to be the app owner or have admin access
   - If you don't see "Setup", you might not have permissions

4. **Try the direct URL:**
   - Copy and paste: `https://play.google.com/console/developers/api-access`
   - Make sure you're logged in first

## 🎯 Once You're on API Access Page

You'll see:
- **Service accounts** section
- **"Link service account"** button
- Click that button to link your service account!
